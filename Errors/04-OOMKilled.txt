container will be given a memory limit if the memory exceeds the limit the k8s will kill the container with oommemory killed
container can use memory above requested if available if memory usgae exceeds limits then container terminated

    name: "test-pod"

          image: nginx

                memeory: 150Mi

    kubectl logs pod <name> -n <ns>         
    kubectl top pod <name> -n <ns> --containers
    kubectl get pod <name> -n <ns> -o jsonpath='{.spec.containers[*].resources}"
