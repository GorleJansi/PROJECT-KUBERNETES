update deployment,configs ,env but application is not update

    deployment rollout only if change in imagetag for small changes tag version might not change
    Image tag did not change
    imagePullPolicy reused a cached mutable tag

    Updated the wrong Deployment

     kubectl rollout history deployment/frontend -n production
