    hpa is cluster level component uses deployment,statefulset to scale ; increase or decrease the replicas of pods based on resoources cpu,mem other metrics provided by metrics server
    deployment,stateful set need resources component in pod, for hpa to compare current cpu collected by metrics server to requests,limits of resources in pod


hpa = current metrics of pods from metrics server - requests of mresource in pod == decide increase pods or decrease
