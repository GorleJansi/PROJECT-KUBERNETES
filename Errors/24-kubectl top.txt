kubectl top returns “Metrics API not available”

kubectl top does not collect CPU and memory itself. 
It queries the metrics.k8s.io API, which is provided by Metrics Server. 
Metrics Server collects current CPU and memory usage from each node’s kubelet.


kubectl top nodes
kubectl top pod -A
kubectl top node <name>
kubectl top pod <name> -n <ns>


# Install Metrics Server
kubectl apply -f https://github.com/kubernetes-sigs/metrics-server/releases/latest/download/components.yaml

# Wait until the Deployment becomes available
kubectl rollout status deployment/metrics-server \
  -n kube-system \
  --timeout=180s

# Check the Pod
kubectl get pods -n kube-system -l k8s-app=metrics-server -o wide

# Check the Metrics API
kubectl get apiservice v1beta1.metrics.k8s.io

# Test metrics
kubectl top nodes
kubectl top pods -A
